**Структура таблицы:**


| Столбец | Что означает | Пример |
| :--- | :--- | :--- |
| **Domain** | Доменное имя, для которого проводилась проверка | `github.com` |
| **Resolved_IP** | IP-адрес, полученный от DNS-сервера | `140.82.121.3` |
| **Traceroute_Success** | Успешность запуска утилиты traceroute (Yes/No) | `Yes` |
| **Reached_Target** | Удалось ли пакету достичь целевого IP-адреса | `Yes` |
| **Total_Hops** | Общее количество зафиксированных прыжков (хопов) | `10` |
| **Hops_Detail** | Сводная информация по каждому хопу (№, IP, задержка) | `H1: 192.168.1.1 (1.4ms) \| ...` |
| **Error** | Описание ошибки, если запрос завершился неудачей | `(пусто)` |
| **Timestamp** | Точная дата и время проведения замера | `2026-04-08 19:46:53` |
